# v1.3.1 — 附件刪除按鈕顯示修正

這是既有 v1.3 備份助手的**介面及快取修正**，不是重新建立備份資料。

## 修正項目
- GitHub v1.3 原始碼已經有附件刪除功能；本次改為固定顯示按鈕，縮小手機畫面時不會被其他操作擠出。
- 更新快取版本及主程式/樣式的資源網址，減少 iPhone 主畫面舊版 PWA 殘留。
- 「刪除」前仍有確認；只刪除本機附件，不刪除已上傳雲端的檔案，也不刪除保存在原始 ZIP 內的檔案。

## 更新方式
1. 將 ZIP 解壓縮後四個檔案放在 GitHub `loyulun23-hash/Allen` 專案根目錄，覆蓋同名檔案。
2. Commit changes；GitHub Pages 部署成功後在**原本使用的瀏覽器或主畫面 App**開啟網站，連網重新載入。
3. 右下角頁尾應顯示 `v1.3.1`，進「附件」檢查每張卡片右側是否有刪除按鈕。
4. 不要透過「清除網站資料」或刪除 App 來更新，否則本機 IndexedDB 可能遺失。

## 限制
- 刪除僅影響目前裝置的備份助手本機資料；不會更動 Google Drive 舊備份。
- 網頁快取更新時仍需有網路連線；Safari PWA 可能要關掉畫面後重新打開。
