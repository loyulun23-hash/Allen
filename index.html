怎麼使用？

不需要 OpenAI API Key，也不需要交出帳號密碼

① 從 ChatGPT 匯出原始資料

在 ChatGPT「設定 → 資料控制 → 匯出資料」提出申請。官方寄送通知後下載 ZIP。也可直接匯入解壓後的 conversations.json 或編號 JSON 檔。

② 匯入這個工具

按主畫面的「匯入聊天備份」。工具在裝置上解析 JSON，保留對話順序與文字、提供搜尋和分類。可保留原始 ZIP（受裝置儲存空間限制）。

③ 原始附件另外加入

如果需要完整保留圖片、聲音、PDF、Excel、3D 模型，請另外從原始來源將檔案加入「附件」區。官方 ZIP 是否包含各原檔需逐項核對，不能只看是否有聊天文字。

④ 打包並儲存到 Drive

第一次在「備份」設定 Google Cloud OAuth Web Client ID，再按「一鍵上傳原始檔到 Drive（不壓縮）」。程式會建立一個新的快照資料夾：聊天以 TXT / JSON 儲存，附件保留原始格式，官方 ZIP 在雲端會以解壓後的檔案保存。完成後核對雲端檔案清單及大小。也可以另下載本機 ZIP；它不會上傳到雲端。

⑤ 加入手機主畫面

iPhone：用 Safari 開啟已部署的 HTTPS 網址，從「分享 → 加入主畫面」安裝。Android：Chrome 選單選「安裝應用程式／加到主畫面」。首次載入後支援離線使用。

隱私與使用限制

本程式沒有自己的後端伺服器、沒有追蹤分析、沒有要求登入 ChatGPT。僅在你主動點擊一鍵備份並完成 Google OAuth 授權後，將各個原始檔送往 Google Drive API。Google 存取權杖只存於記憶體，不寫入本機儲存。手機上的儲存仍有被清除或容量不足風險。
