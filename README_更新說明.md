# 聊天備份助手 v1.4 — 自動略過重複與日期分類檔名

## 新功能
- Google Drive 端採穩定資料夾 `ChatGPT_備份助手_一鍵上傳/分類歸檔/工作|投資|生活|感情|未分類`，不再每次上傳新的完整快照資料夾。
- 檔名：`YYYY-MM-DD_分類_原始檔案名稱.副檔名`。聊天優先使用對話更新日期，附件優先使用原始檔日期（若來源缺少則取匯入日期）。
- 用檔案原始位元組計算 SHA-256；Drive 上對同一 OAuth App 上傳的 v1.4 檔案保存私有 appProperties 內容指紋。每次上傳前先掃描先前已備份內容，相同大小與 SHA-256 自動略過，不再重複上傳。
- v1.3 舊版備份：為避免誤判，僅對符合名稱與大小、且 <=12 MiB 的候選檔案下載至記憶體進行 SHA-256 精確比對；其餘舊檔可能會再次上傳，程式不會擅自刪掉舊檔。
- 同名同日期但內容不同，保留新舊兩份，於檔名後追加短 SHA-256，避免覆蓋重要資料。
- 如果網路中斷，已成功上傳者保留，下次重新按下可跳過已經成功的內容。
- 繼續保留 v1.3.2 的「對話」及「附件」刪除按鈕。

## 「自動刪除」的安全界線
- **不會刪除任何原始檔、聊天內容、Google Drive 舊 ZIP 或先前已上傳的備份。**
- 本次要求中的「自動刪除重複」實作為 **不再上傳完全相同的內容**，不是自動移到垃圾桶。既有舊備份如需清理，請先由你確認。
- 程式只能查核此 Google OAuth 用戶端可存取的、自己建立的雲端備份資料夾內容。手動放到其他地方的檔案未必可見。
- 嚴格完全相同內容才略過；檔名相同但內容改動，應另存新檔。
- 這項功能不能自動取得 ChatGPT App 裡的新聊天。

## 更新 GitHub
1. 解壓 ZIP，將 app.js、index.html、styles.css、sw.js、README_更新說明.md 五檔上傳到 https://github.com/loyulun23-hash/Allen 的 main 最外層，Commit changes。
2. 等 GitHub Pages 最新部署成功，重新開啟 https://loyulun23-hash.github.io/Allen/ 。檢查頁尾為 v1.4。
3. 不要清除瀏覽器／Safari 的網站資料；否則尚未另存的本機附件可能丟失。
4. 第一次使用建議用一個小檔案測試：上傳一次後再按一次，確認第二次顯示「已備份略過」。
